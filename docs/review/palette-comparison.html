Salary Desk · five paired palette choices

One shared semantic-token structure, ten previews, identical illustrative UI. This is a decision artifact, not an application theme picker. All canvases and panels are predominantly neutral; accent is reserved for actions, selected states and focus. Recommendation: P1 Graphite + Lime.
